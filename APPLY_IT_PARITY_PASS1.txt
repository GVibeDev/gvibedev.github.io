-------
Align the main Italian public pages with the CURRENT English Astro pages,
instead of rendering preserved historical HTML snapshots from it-pages.json.

This is intentionally PASS 1.

Aligned in this patch:
- Home
- Projects index
- Web Apps index
- Tools index
- Worlds index
- MO2 Projects index
- Manifesto
- Contact
- About legacy HTML cleanup (About itself is already shared EN/IT)

Also:

       npm run build

   /it/
