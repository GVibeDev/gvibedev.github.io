Politica dei runtime

Showcase ed eseguibile restano separati.

Le pagine progetto restano parte di GVibeDev.cc e documentano screenshot, decisioni di design e stato di sviluppo. Le applicazioni browser vengono distribuite dai propri repository, così un aggiornamento del gioco non richiede di copiare l’intero runtime nel repository del portfolio.

Gli strumenti desktop nativi non vengono forzati dentro questo modello. Continuano a usare pagine progetto e download di release verificati; una demo browser viene aggiunta soltanto quando esiste davvero un’edizione web.
