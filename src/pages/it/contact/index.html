Contatti

Progetti, domande, idee strane.

GVibeDev è un progetto personale, non un'azienda né un help desk. Se vuoi parlare di uno dei progetti, segnalare un problema, discutere una collaborazione o semplicemente chiedere come è stato costruito qualcosa, questi sono i canali migliori per contattarmi.

GitHub

Repository, codice e issue

Per discussioni legate a un repository, domande sul codice o segnalazioni di problemi, GitHub è il canale più diretto e utile.

github.com/GVibeDev
Email

Messaggi generali

Per contatti generali, collaborazioni, questioni editoriali, stampa o conversazioni più ampie sui progetti, l'email è l'opzione migliore.

gvibedev@gmail.com
Issue di progetto

Preferisci una GitHub Issue

Se il messaggio riguarda un bug specifico, un repository o un dettaglio di implementazione, quando possibile apri una issue nel progetto relativo.

Messaggio generale

Preferisci l'email

Se l'argomento è più ampio di un singolo repository, l'email mantiene la conversazione più semplice.

Domanda su codice / repository

GitHub funziona meglio

Le domande tecniche pubbliche spesso funzionano meglio su GitHub perché restano collegate al codice e possono aiutare altri in seguito.

Collaborazioni / stampa / altro

Email

Se il messaggio è personale, editoriale o esplorativo, l'email è il canale più appropriato.

Solo contatti pubblici

Diretto, senza pressioni e non corporate.

Niente funnel di prenotazione, dipartimenti immaginari o numeri di telefono e indirizzi privati. Solo pochi canali pubblici chiari.
