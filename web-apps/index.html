Runtime policy

Showcase and executable stay separate.

Project pages remain part of GVibeDev.cc and document screenshots, design decisions and development status. Browser applications are deployed from their own repositories so a game update does not require copying the whole runtime into the portfolio repository.

Native desktop tools are not forced into this model. They continue to use project pages and verified release downloads; a browser demo is only added when a real web edition exists.
