Contact

Projects, questions, strange ideas.

GVibeDev is a personal project, not a company or a support desk. If you want to talk about one of the projects, report an issue, discuss a collaboration or simply ask how something was built, these are the best places to reach me.

GitHub

Repositories, code and issues

For repository-level discussion, code questions or issue reporting, GitHub is the most direct and useful channel.

github.com/GVibeDev
Email

General messages

For general contact, collaborations, editorial questions, press or broader project conversations, email is the better option.

gvibedev@gmail.com
Project issue

Prefer GitHub Issue

If the message concerns a specific bug, repository or implementation detail, open an issue on the relevant project when possible.

General message

Prefer email

If the topic is broader than one repository, email keeps the conversation simpler.

Code / repository question

GitHub works best

Public technical questions are often better on GitHub because they remain attached to the code and may help others later.

Collaboration / press / other

Email

If the message is personal, editorial or exploratory, email is the more appropriate channel.

Public contact only

Low-pressure, direct and non-corporate.

No booking funnels, no fictional departments and no private phone numbers or addresses. Just a small set of clear public channels.
