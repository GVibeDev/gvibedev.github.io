GVibeDev.cc V0.17 — NAVDATA HOTFIX
==================================

CAUSE
-----
MainNav.astro and MobileNav.astro render labels with:

    strings.nav[item.key]

but the navigation configuration currently published on GitHub contains only:

    { label, href }

and has no `key`.

During Astro production build, `item.key` is therefore undefined and the generated
English navigation anchors contain no text. The GitHub link remains visible because
it is hard-coded separately.

The Italian pages remain visible because they are currently static localized pages
whose navigation labels were already compiled into their HTML.

FIX
---
Replace only:

    src/config/navigation.ts

Then:

    npm run build

Before pushing, inspect the generated:

    dist/index.html

and confirm the header contains visible labels such as:

    Home
    Projects
    Web Apps
    Tools
    Worlds
    BiggityKot
    Manifesto
    About
    Contact

Then commit and push.

This patch also restores the full page routes for Web Apps, BiggityKot and Manifesto
instead of the stale homepage anchors.
