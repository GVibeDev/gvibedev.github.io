CHANGES

1. Arena Rubra live URL normalization
   Replaces:
       https://gvibedev.github.io/ArenaRubra/
   with:
       https://gvibedev.cc/ArenaRubra/

   The GitHub Pages API reports the ArenaRubra Pages html_url on the custom
   domain, so the portfolio should link directly to the canonical live host.

2. B&W Survivors raw runtime indexing policy
   Adds:
       <meta name="robots" content="noindex, nofollow">

   The project page remains indexable. Only the raw /apps/bw-survivors/
   application runtime is excluded from search indexing.
