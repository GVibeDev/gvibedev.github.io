# GVibeDev.cc V0.21 — Implementation Status

## Implemented

### Shared architecture
- Shared bilingual `ProductDistributionSurface`.
- Product surface injection from `BaseLayout`.
- Data-driven status / lifecycle model in the project collection schema.
- Real endpoints render as anchors.
- Planned or unpublished endpoints render as status cards only.
- Distribution CTA analytics attributes are present but analytics remains disabled.

- Download: explicitly not published.
- Tutorials: planned.
- Changelog: planned.
- GitHub: explicitly not published.

### Arena Rubra
- Play: real public browser endpoint.

- Support: real GVibeDev Support page.

- Documentation / Changelog: planned, not linked.

## Architecture note

V0.21 deliberately uses the V0.20 shared shell as the injection point. This keeps EN and IT behavior aligned and avoids reintroducing duplicated page-level product logic.
