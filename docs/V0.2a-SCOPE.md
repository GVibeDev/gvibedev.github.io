# GV-PORTFOLIO V0.2a — Card Media Context + Fixed Crop

## Goal
Separate project-card media from page hero media and prevent an image's intrinsic aspect ratio from changing the height of the project-card grid.

## Included
- Optional `cardImage`, `cardImageAlt`, and `cardImagePosition` project fields.
- `ProjectCard` fallback contract: `cardImage` → `cover`.
- Fixed 4:3 card-media viewport.
- Explicit `height: 100%` + `object-fit: cover` so intrinsic image dimensions cannot stretch the card.
- Dedicated 1200×900 WebP derivative for Arena Rubra, produced from the author-provided vertical banner.

## Not changed
- Project-page hero.
- Gallery.
- Project-page route/content.
- Homepage section order.
- Responsive grid structure.
- Dependencies or package lock.

## Acceptance gate
- Featured cards remain aligned even if one project has a portrait/vertical source image.
- Arena Rubra title remains readable in its card artwork.
- No visible image distortion.
- No layout shift caused by natural image ratio.
- `/projects/arena-rubra-digital/` still uses the existing hero artwork.
- `npm run build` succeeds.
