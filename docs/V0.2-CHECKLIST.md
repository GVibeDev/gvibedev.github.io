- [ ] Keep the V0.1-generated `package-lock.json` in the working repository.
- [ ] Copy/merge V0.2 files over the validated V0.1 working tree.
- [ ] `npm install` completes.
- [ ] `npm run dev` starts.
- [ ] `npm run build` completes.

- [ ] 360 px: no horizontal overflow.

- [ ] Keyboard focus remains visible.
- [ ] Gallery thumbnails work as ordinary image links without JavaScript.
