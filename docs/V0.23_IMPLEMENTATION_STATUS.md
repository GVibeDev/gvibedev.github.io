# GVibeDev.cc V0.23 — Implementation Status

## Implemented

- central commercial provider resolver;
- provider-aware project CTA schema;
- provider-aware Product Hub distribution items;
- commercial action vocabulary:
  - Support
  - Download
  - Wishlist
  - Buy
  - Back
  - Follow development
- unified `conversion-cta` analytics attribute contract;
- PayPal endpoint-kind configuration (`donate-page` / `paypal-me`);
- optional QR asset field for future Support presentation;
- commercial activation documentation.

## Active

- none of the new commercial providers.

Existing non-commercial public endpoints remain unchanged:
- GitHub;
- Arena Rubra Play.

## Deliberately inactive

- PayPal Support payment endpoint;
- itch.io;
- Steam;
- Kickstarter;
- Patreon;
- analytics collection.

## External input required for activation

- final PayPal public support endpoint;
- optional PayPal QR asset selected for public use;
- real Sprite Studio distribution/store URL;
- real Steam product page if/when applicable;
- real Kickstarter campaign if/when applicable;
- real Patreon page if/when applicable;
- analytics account/script before conversion events can be collected.
