# GV-PORTFOLIO V0.7 — Site scope

## Milestone
**Web Apps Foundation + Arena Rubra Online Runtime**

## Baseline
GV-PORTFOLIO V0.6a.

## Included
- Create `/web-apps/` as a real catalog page.
- Route the navigation item `Web Apps` to that page.
- Keep the catalog data-driven from the existing `projects` collection.
- Show public-runtime counts based only on actual `launchUrl` values.
- Add the Arena Rubra runtime link only after its independent GitHub Pages deployment is verified.
- Preserve the existing Arena Rubra project showcase and repository link.
- Leave Arena Rubra Card Composer as a tracked web-app entry without fabricating a runtime, repository or finished project page.

## Out of scope
- No Card Composer standalone repository is created by the portfolio patch.
- No iframe embeds.
- No desktop Tool is converted to a web application.
- No changes to gameplay, AI, balancing or assets inside Arena Rubra.
- No npm dependency.
