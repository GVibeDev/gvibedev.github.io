## Setup truth rule

The WanGP dependency guide records the configuration validated during development. It does not claim that other WanGP environments are impossible. The important frozen constraint for this project is that the working local bridge used an isolated Python 3.11.14 interpreter; newer global Python 3.13/3.14 installations previously produced a NOT READY bridge result.
