# V0.20 — Implementation Status

## Implemented

- 18 Italian full-document HTML routes converted to `.astro` routes.
- one shared localized-content page renderer;
- Italian metadata / translated body source centralized;
- shared `BaseLayout` for EN and IT;
- shared SiteHeader / MainNav / MobileNav / LanguageSwitch / SiteFooter;
- analytics adapter now reaches converted Italian routes from the same shell;
- canonical / hreflang / structured data no longer copied into Italian full documents;
- V0.19 Support routes added to sitemap;
- ecosystem release marker advanced to V0.20.

## Preserved

- all existing `/it/.../` URLs;
- translated Italian body content;
- project links and previews;
- current visual identity;
- existing route-specific validated styles;
- `/it/support/` native Astro implementation.

## Transitional / not yet fully migrated

- most Italian page bodies are still preserved localized markup fragments rather than the exact same semantic Astro body components used by English;
- several Italian page bodies therefore remain content-level duplicates;
- a small compatibility dependency on validated `public/_astro` route CSS remains.

## Not changed

- PayPal is still not activated without a real URL;
- analytics is still disabled without a real provider/account configuration;
- no future social/store/crowdfunding account is exposed;
- Community Depot and commercial product surfaces are not implemented.
