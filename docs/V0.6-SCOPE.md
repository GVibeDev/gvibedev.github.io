# GV-PORTFOLIO V0.6 — Scope

## Milestone
**Worlds Editorial Foundation + Unum Sunt: Radix Machinae**

## Baseline
GV-PORTFOLIO V0.5a.

## Included
- Add a reusable `EditorialProjectLayout` for `kind: world` projects.
- Route world project pages to the editorial layout while preserving Tool and standard project layouts.
- Add `/worlds/` as a real catalog route and point the main navigation to it.
- Publish `/projects/unum-sunt/` as the first complete editorial project page.
- Freeze the public status as **Novel in Development** with **Italian & English Preview Available**.
- Add four author-provided visual assets, optimized for web delivery.
- Add a dedicated 4:3 project-card composition and a social/OG image.
- Integrate the Italian 38-page and English 32-page previews as unchanged public PDFs.
- Add reusable editorial hero, chapter, theme, preview-library, quote and endcap components.
- Keep the main site/project copy in English while presenting both preview languages with equal prominence.

## Out of scope
- No site-wide Italian localization.
- No custom PDF reader or iframe-based reader.
- No EPUB generation.
- No lore wiki, character database or timeline.
- No Arena Rubra board-game project page.
- No publication date, completion percentage or final chapter count is invented.
- No npm dependency is added.
