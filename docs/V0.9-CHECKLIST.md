## Source discipline

The public rules copy is grounded in `Arena_Rubra_Regolamento_Starter_Edizione_Utente(1).docx`.
The older statistics/conversion register is treated as a historical extraction source only because it explicitly records a pre-conversion DEF state. V0.9 does not use that older conversion status to override the later Starter rulebook.
