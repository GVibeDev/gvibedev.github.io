# GVibeDev.cc V0.24 — Implementation Status

## Scope

V0.24 refreshes only the public Unum Sunt Sprite Studio product surface and the site release marker/documentation around it. Commercial/social activation remains frozen at the V0.23 baseline.

### Windows/runtime architecture
- PyInstaller onedir core;

- build automation with tests, manifest, ZIP and SHA-256;

- managed/external WanGP distinction;
- resumable verified downloads;
- Authenticode verification for downloaded Windows installers;
- temporary Hugging Face credential handling for gated acquisition;
- repair/update/health-check and opt-in independent cleanup.

## Explicit constraints preserved

- No fixed minimum GPU/VRAM/RAM model threshold is published from R5c2.
- Effective local-generation compatibility is diagnosed against the actual driver/PyTorch/CUDA runtime.
- External WanGP installations are not moved, renamed, repaired or removed by managed maintenance.
- Krea 2 end-to-end setup remains pending after R5c6 and is not presented as completed.
- PayPal, itch.io, Steam, Kickstarter, Patreon and analytics remain inactive.
