# GV-PORTFOLIO V0.1 — Scope Freeze

## Objective

Create the smallest complete and testable visual/technical foundation for `gvibedev.cc` without opening unrelated project-page or distribution work.

## Included

1. Repository structure.
2. Astro static build configuration.
3. GitHub Pages workflow.
4. Design system / brand tokens.
5. Header and navigation.
6. Responsive hero.
7. Homepage skeleton.
8. Project card system.
9. Content schema for project metadata.
10. Featured projects section.
11. Web Apps section.
12. Tools & Downloads section.
13. Worlds / Ongoing Projects section.
14. BiggityKot section.
15. Short manifesto section.
16. GitHub panel.
17. Footer.
18. Base accessibility and reduced-motion support.
19. Real supplied brand assets and optimized derivatives.

## Explicitly out of scope

- Full autonomous project pages.
- Project screenshot galleries.
- Launch URLs not yet supplied.
- Repository URLs not yet supplied per project.
- GitHub Release download buttons not yet supplied.
- Hosting Arena Rubra or Card Composer inside this repository.
- Installer / EXE / APK files.
- Analytics.
- Contact forms.
- CMS.
- Search.
- Blog/news system.
- Complex animation.
- Final multilingual strategy.
- Final DNS activation at Spaceship.
- Automated SEO sitemap integration.

## Frozen architectural rules

- `gvibedev.github.io` is the hub, not a monorepo for every GVibeDev application.
- Web apps and downloadable tools remain independent projects/repositories.
- Heavy installers belong in GitHub Releases, not the portfolio repository.
- Missing project facts remain absent rather than invented.
- Homepage cards are text-first until real project media is supplied.
- V0.1 must remain usable without client-side JavaScript.
