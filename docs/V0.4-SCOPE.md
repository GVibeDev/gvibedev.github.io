- Publish the first complete Rubra Packager / Rubra-Composer tool page.
- Freeze the public site status at **v0.5.0 — Active Development**.
- Link the verified public repository `GVibeDev/Rubra-Composer`.
- Keep the release/download CTA absent because no GitHub Release is linked yet.
- Add five author-provided development captures, optimized for web delivery.
- Add a dedicated 4:3 card cover and Open Graph image.
- Document the workflow `Register → Preflight → Fix → Build → Verify`.
- Document Windows and Android packaging paths.
- Document the explicit npm trust boundary.
- Add a compact install/start guide for the Windows launcher.
- Generalize the V0.3 setup/dependency component so different tools can supply their own copy and requirement-group labels.
- Preserve Sprite Studio's existing setup wording through backward-compatible defaults.
- Make ToolProjectLayout publication notes reflect actual repository/release availability instead of assuming every tool is unpublished.

## Explicitly out of scope
- No GitHub Release is created.
- No installer or binary is hosted inside the portfolio repository.
- No Rubra Packager source code is modified.
- No claim is made that backend/SSR projects are supported.
- No change to Arena Rubra project-page layout.
- No change to the global visual design system.
- No new npm dependency.
