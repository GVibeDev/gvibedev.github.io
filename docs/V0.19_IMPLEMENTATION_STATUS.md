## Known architectural debt

The V0.17 Italian localization is currently hybrid: many Italian pages are static HTML source pages while English pages use shared Astro components.

V0.19 does not destabilize those validated pages. New Support routes are shared Astro pages, but a later milestone should consolidate the Italian page shell so global structural changes and analytics do not require static-page touch-ups.
