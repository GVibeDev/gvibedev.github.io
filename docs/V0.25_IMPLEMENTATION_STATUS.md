# GVibeDev.cc V0.25 — Implementation Status

## Implemented

### Sprite Studio screenshot presentation
- New `ScreenshotCarousel.astro` component.
- V0.24 screenshot set reused without asset changes.
- Existing EN/IT captions and alt text preserved.
- Gallery moved from after the long capabilities section to immediately after the 14-workspace overview.

### Interaction
- native horizontal scrolling;
- CSS scroll snap;
- touch / trackpad support;
- previous / next buttons;
- Left / Right keyboard navigation when the carousel viewport is focused;
- active `01 / 13` counter;
- inline horizontal thumbnail strip;
- active thumbnail state;
- thumbnail selection scrolls the main rail;
- main screenshot opens the existing full-resolution style dialog.

### Visual treatment
- translucent layer rather than a solid gallery grid;
- subtle blue/red ambient gradients;
- contained screenshots use `object-fit: contain`, avoiding UI cropping;
- responsive thumbnail sizes;
- mobile horizontal overflow contained inside the carousel.

### Accessibility
- 44px navigation controls;
- labelled carousel region;
- labelled slides;
- `aria-current` on selected thumbnail;
- disabled previous/next controls at rail boundaries;
- reduced-motion mode disables smooth scrolling/transitions.

## Not changed
- screenshot files;
- screenshot captions;
- project feature copy;
- Product Hub;
- repository / Releases endpoints;
- sitemap;
- other project galleries;
- commercial/activation configuration.
