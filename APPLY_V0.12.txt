Milestone:
GV-PORTFOLIO V0.12 — Arena Rubra Shared Content Architecture + Tabletop Design / Playtest Expansion

What this patch changes
-----------------------
1. Adds canonical reusable Arena Rubra data:
   src/data/shared/arena-rubra.ts

   src/components/arena-rubra/ArenaRubraFactionGrid.astro

   public/assets/projects/arena-rubra/shared/

No npm dependencies are added.
No routes are changed.
No existing tabletop hero, gallery, sample cards or prototype disclaimer are removed.

IMPORTANT TEST-COUNT NOTE
-------------------------
The supplied canonical website copy marks the exact “1,000+ matches” claim as pending verification.
The supplied testing text supports “hundreds of full test matches”, large 100-match batches, broader testing approaching four figures, and thousands of regression checks.
Therefore this patch intentionally uses the conservative verified wording and DOES NOT publish “1,000+”.

Application
-----------
1. Stop `npm run dev`.
2. Back up / commit the validated V0.11 baseline.
3. Copy the CONTENTS of `gvibedev-v0.12-arena-shared-tabletop` into the repository root.
4. Allow overwrite of the two existing tabletop files.
5. Do not delete package-lock.json or node_modules.
6. Run `VERIFY_V0.12.bat`.
7. Run `npm run dev`.
8. Test `/projects/arena-rubra-board-game/` on desktop and mobile widths.
9. Run `npm run build` and `npm run preview`.
