# V0.8a validation checklist

## Runtime repository
- Create public repository `pizza-990/black-white-survivors`.
- Copy the contents of `black-white-survivors-pages-v0.8a/` to its root.
- Settings → Pages → Source: GitHub Actions.
- Push `main` and wait for the Pages workflow to pass.
- Open `https://pizza-990.github.io/black-white-survivors/`.
- Confirm LAN is not visible in the hosted menu.
- Confirm IT/EN switch, Loadout, Play Solo, Character, Black Box, Encyclopedia and Weapon Tester.
- Start a solo run; confirm enemies, waves, boss bar and between-wave shop.
- Check landscape mobile/touch controls on a phone if available.
- Reload and confirm browser save/language persistence.

## Portfolio
- Apply `gvibedev-site-v0.8a-patch/` only after the runtime URL works.
- Run `npm run dev`.
- Open `/biggitykot/` and `/projects/bw-survivors/`.
- Confirm `Play online` opens the hosted runtime.
- Confirm `Download 0.9A build` still downloads the original archive.
- Confirm `BiggityKot on GitHub` still points to `pizza-990`.
- Run `npm run build` and `npm run preview`.
